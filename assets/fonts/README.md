# Шрифты

Гарнитуры уже лежат в этой папке, скачивать ничего не нужно.
Обе бесплатные (SIL Open Font License), с кириллицей, ставятся локально —
ни одной ссылки на CDN в вёрстке нет.

| Гарнитура | Где используется | Начертания |
|---|---|---|
| **Onest** | заголовки, цифры, кнопки | 500, 700 |
| **Golos Text** | основной текст и подписи | 400, 600 |

Каждое начертание разбито на два поднабора — как это делает сам Google Fonts:

```
onest-700-cyrillic.woff2   6 КБ   U+0400–045F и соседние
onest-700-latin.woff2     14 КБ   латиница, знаки, ₽ и №
```

Браузер грузит только то, что реально встретилось на странице.
Правила `@font-face` с `unicode-range` — в начале `assets/css/styles.css`.
Два кириллических файла для первого экрана предзагружаются через
`<link rel="preload">` в `index.html`, чтобы заголовок не мигал системным шрифтом.

Итого весь набор — 96 КБ.

Источник: fonts.google.com/specimen/Onest и fonts.google.com/specimen/Golos+Text
