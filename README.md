# Лендинг «Первый Луч» — парные под ключ и банные печи

Конверсионный лендинг под холодный трафик Яндекс.Директа. Два продукта на одной
странице: отделка парной под ключ и банные печи с монтажом. Ядро — конфигуратор
в первом экране с живой вилкой цены и автоподбором модели печи под объём парной.

Статика: HTML + CSS + ванильный JS, без сборки и зависимостей.
Открывается двойным кликом по `index.html`.

### 3. Подключить приём заявок

Лендинг статический, поэтому токен телеграм-бота нельзя положить в браузер —
его украдут за сутки. Нужен маленький серверный приёмник.
Готовый код и инструкция: **`api/README.md`** (15 минут, бесплатно).

Пока приёмник не подключён, при открытии с диска или с `localhost` формы
работают в демо-режиме: показывают успех, но никуда не отправляют.

### 4. Завести цели в Яндекс.Метрике

Тип — «JavaScript-событие»:

| Цель | Когда срабатывает | Роль |
|---|---|---|
| `lead_submitted` | заявка отправлена | **главная цель Директа** |
| `calc_started` | тронул калькулятор | микроконверсия для обучения |
| `calc_cta_click` | нажал «В мессенджер» / «По телефону» | микроконверсия |
| `phone_click` | клик по номеру | звонки с мобильных |
| `messenger_click` | клик по WhatsApp / Telegram | |
| `video_play` | запустил видео объекта | вовлечение |
| `scroll_75` | долистал до 75% | вовлечение |
| `thanks_page_view` | дошёл до `spasibo.html` | дубль главной цели |

Для Директа: ведите оптимизацию на `lead_submitted`, а на старте (пока конверсий
мало) обучайте кампании на `calc_started` + `calc_cta_click`.

Файл `docs/DESIGN_BRIEF.md` — готовый бриф с границами правок и промптом.

## Как устроен конфигуратор

Один блок, три сценария. Первый вопрос делит трафик, дальше поля меняются:

| Сценарий | Что спрашиваем | Что считаем |
|---|---|---|
| **Только печь** | площадь парной, стекло | диапазон по печам, подходящим под объём |
| **Парная под ключ** | площадь, стекло, тип парной, пакет | диапазон прайса, пересчитанный по метражу |

**Правки Влада 31.08.2026 — что калькулятор больше не делает.** Он не привязывает
к проекту конкретную печь, не показывает цены допов, не спрашивает «дрова или
электро» и класс печи. Наш уровень — диапазон, а не смета: смету считает инженер
после замера. Конкретную модель печи человек выбирает сам в каталоге ниже по
странице — оттуда `LuchCalc.openStove()` открывает поп-ап с ценой этой модели.

Объём парной = площадь × 2,4 м плюс стекло: стеклянная дверь или окно внутри
дома добавляют 1 м³, стекло или стена на улицу — 2 м³ (`LUCH.calcRules`).
Надбавки «+50% за внешнюю стену» больше нет.

Цена парной под ключ = диапазон из `LUCH.packages[].projectPrice`, посчитанный
на 6 м² (`calcRules.baseArea`), умноженный на `площадь / 6`. Ниже базовой
площади цена не опускается: нижняя граница прайса — это порог. Авторский пакет
и хамам за метр не тарифицируются, у них только точка входа «от».

**Приземление кампаний Директа.** Вкладку можно задать адресом:

| Ссылка | Что открывается |
|---|---|
| `/?product=stove` | «Только печь» — для кампаний по запросам про печи |
| `/?product=finish` | «Отделка под ключ» — для «отделка парной», «баня под ключ» |
| `/?product=both` | «Печь + отделка» — общие кампании и ретаргет |
| `/?product=both&pkg=premium` | плюс сразу пакет «Премиум» |

Метка уходит в заявку полем `entry_product` — видно, из какой кампании лид.

По кнопке открывается модалка: имя, телефон и один квалифицирующий вопрос
«когда планируете начать». В заявку уходит вся конфигурация плюс атрибуция.

## Деплой

Лендинг развёрнут на GitHub Pages:
**https://chagagagaga.github.io/1luch-banya-landing/**

Любой push в ветку `main` пересобирает страницу автоматически за 1–2 минуты:

```bash
git add -A && git commit -m "правки" && git push
```

Свой домен (например `banya.1-luch.ru`) подключается так:
1. У регистратора домена добавьте CNAME-запись `banya` → `chagagagaga.github.io`
2. В настройках репозитория → Pages → Custom domain впишите `banya.1-luch.ru`
3. Дождитесь выпуска сертификата и включите Enforce HTTPS

```bash
python3 -m http.server 8080
# http://localhost:8080
```

отправки форм.

  но сам сплиттер не ставил: сначала нужен трафик.
