# Лендинг «Первый Луч» — парные под ключ и банные печи

Конверсионный лендинг под холодный трафик Яндекс.Директа. Два продукта на одной
странице: отделка парной под ключ и банные печи с монтажом. Ядро — конфигуратор
в первом экране с живой вилкой цены и автоподбором модели печи под объём парной.

Статика: HTML + CSS + ванильный JS, без сборки и зависимостей.
Открывается двойным кликом по `index.html`.

### 3. Подключить приём заявок

Лендинг статический, поэтому токен телеграм-бота нельзя положить в браузер —
его украдут за сутки. Нужен маленький серверный приёмник.
Готовый код и инструкция: **`api/README.md`** (15 минут, бесплатно).

Пока приёмник не подключён, при открытии с диска или с `localhost` формы
работают в демо-режиме: показывают успех, но никуда не отправляют.

### 4. Завести цели в Яндекс.Метрике

Тип — «JavaScript-событие»:

| Цель | Когда срабатывает | Роль |
|---|---|---|
| `lead_submitted` | заявка отправлена | **главная цель Директа** |
| `calc_started` | тронул калькулятор | микроконверсия для обучения |
| `calc_cta_click` | нажал «В мессенджер» / «По телефону» | микроконверсия |
| `phone_click` | клик по номеру | звонки с мобильных |
| `messenger_click` | клик по WhatsApp / Telegram | |
| `video_play` | запустил видео объекта | вовлечение |
| `scroll_75` | долистал до 75% | вовлечение |
| `thanks_page_view` | дошёл до `spasibo.html` | дубль главной цели |

Для Директа: ведите оптимизацию на `lead_submitted`, а на старте (пока конверсий
мало) обучайте кампании на `calc_started` + `calc_cta_click`.

Файл `docs/DESIGN_BRIEF.md` — готовый бриф с границами правок и промптом.

## Как устроен конфигуратор

Один блок, три сценария. Первый вопрос делит трафик, дальше поля меняются:

| Сценарий | Что спрашиваем | Что считаем |
|---|---|---|
| **Только печь** | объём парной, топливо, класс | цена подобранной модели + обвязка |
| **Отделка под ключ** | площадь парной, тип парной, пакет | м² × цена пакета + допы |
| **Печь + отделка** | всё вместе | сумма минус подарки: монтаж, дымоход, −5% на работы |

Печь подбирается автоматически: фильтр по топливу и объёму, затем сортировка
по близости к выбранному классу и точности попадания в диапазон. Модель
показывается прямо в конфигураторе с фото и ценой.

Итог выводится вилкой (`от X до Y`, верх +22%) — честнее одной цифры и не пугает.

По кнопке открывается модалка: имя, телефон и один квалифицирующий вопрос
«когда планируете начать». В заявку уходит вся конфигурация плюс атрибуция.

---

## Что уходит в заявке

```
Имя, телефон, предпочтительный канал связи, сроки, комментарий
Конфигурация: сценарий, площадь, объём, пакет, тип парной, модель печи,
              выбранные допы, вилка расчёта, выгода комплекта
Атрибуция:    первый и последний источник, все utm_*, yclid, реферер,
              количество визитов до заявки, ym_uid для склейки с Метрикой,
              страница, разрешение экрана, устройство
```

# http://localhost:8080

отправки форм.

## Что осознанно НЕ сделано

- **Видеоотзывы** — превью и ссылки взяты с сайта `spa.termostatus.com`.
  На роликах брендинг «Термостатус» и лицо их менеджера. Перед запуском решите:
  перезалить под своим брендом, оставить как есть или убрать блок
  (секция `#videos` в `index.html`, список — в `assets/js/main.js`).
- **Фото объектов** — оттуда же. Если планируете судиться с подрядчиками
  за авторские права, сначала согласуйте использование внутри группы компаний.
- **Карта объектов** — не делал, чтобы не тащить внешний API Яндекс.Карт
  в первый экран. Если нужна — добавим отдельной секцией с ленивой загрузкой.
- **A/B-тесты** — заложены точки (заголовок, вилка цены, три пакета),
  но сам сплиттер не ставил: сначала нужен трафик.
